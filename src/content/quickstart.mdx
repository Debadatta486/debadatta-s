This quickstart shows how to retrieve a sample post using Postman or `curl`. No account or API key is required.

## Before you begin

- Install [Postman](https://www.postman.com/downloads/) if you want to follow the Postman steps.
- Alternatively, use a terminal with `curl` installed.
- Make sure the environment can access `jsonplaceholder.typicode.com`.

## Make your first request

<Steps>
  <Step title="Create a GET request">
    Open Postman, create an HTTP request, select **GET**, and enter this URL:

    ```http
    https://jsonplaceholder.typicode.com/posts/1
    ```
  </Step>
  <Step title="Send the request">
    Select **Send**. The API should return a successful response containing a sample post.
  </Step>
  <Step title="Inspect the response">
    Verify that the HTTP status is `200 OK` and that the JSON response includes these fields:

    ```json
    {
      "userId": 1,
      "id": 1,
      "title": "sunt aut facere repellat provident occaecati excepturi optio reprehenderit",
      "body": "quia et suscipit suscipit recusandae consequuntur expedita et cum reprehenderit molestiae ut ut quas totam"
    }
    ```

    The `title` and `body` values are sample data. Compare the actual response with the response displayed by the API.
  </Step>
</Steps>

## Try the request with curl

Run this command in a terminal:

```bash
curl -i https://jsonplaceholder.typicode.com/posts/1
```

The `-i` option includes the HTTP response headers so you can inspect the status code as well as the response body.

## Troubleshooting

| Symptom | What to check |
| --- | --- |
| No response | Check network connectivity and whether the API host is reachable. |
| A connection or DNS error | Check the URL, network settings, proxy, and DNS configuration. |
| Unexpected response | Confirm the request URL is `/posts/1` and the method is `GET`. |
